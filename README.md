# شیشه‌های عاشقانه (نسخه‌ی فارسی)

ترجمه‌ی کامل فارسی و راست‌چین‌شده‌ی پروژه‌ی **Non-kink Jars / Romantic Jars**.

- 🔗 پروژه‌ی اصلی: https://romance.blackwhiskercult.com/

یک پرسش‌نامه‌ی تک‌صفحه‌ای درباره‌ی محبت و نزدیکی (بغل، بوسه، ماساژ، هدیه و ...): یه رنگ انتخاب کن، به هر شیشه از ۱ تا ۵ امتیاز بده و عکسش رو ذخیره یا برای پارتنرت بفرست.
همه‌چیز داخل مرورگر اجرا می‌شه؛ هیچ چیزی آپلود نمی‌شه.

## امکانات

- همه‌ی متن‌ها فارسی و صفحه راست‌چین (RTL) با فونت وزیرمتن (مجوز OFL، داخل پوشه‌ی `fonts`؛ بدون وابستگی به گوگل‌فونت).
- زیر هر شیشه یه توضیح ساده‌ی فارسی (با نام انگلیسی مورد) هست؛ آرایه‌ی `JARS_INFO` در `index.html`.
- **ذخیره‌ی دو مرحله‌ای:** اول قالب انتخاب می‌شه:
  - تصویر ساده
  - تصویر همراه توضیحات (با گزینه‌ی «توضیح همه‌ی شیشه‌ها»)
  - استوری ۹:۱۶ (اینستاگرام و تلگرام)
  - پست ۴:۵ (اینستاگرام، ایکس، کانال تلگرام)
  - PDF با کیفیت بالا (از پنجره‌ی چاپ مرورگر؛ مقصد: «ذخیره به‌صورت PDF»؛ توضیحات متن واقعی و لینک‌ها قابل کلیکن)
- **اشتراک‌گذاری:** بعد از ساخت تصویر:
  - «اشتراک‌گذاری تصویر» (روی گوشی): منوی اشتراک‌گذاری گوشی باز می‌شه و می‌تونی اینستاگرام ← استوری، تلگرام، واتساپ و ... رو انتخاب کنی.
  - «ذخیره روی دستگاه»
  - دکمه‌های ایکس (X)، تلگرام و واتساپ برای فرستادن لینک سایت (فقط وقتی سایت روی آدرس آنلاین باشه). ایکس و اینستاگرام اجازه نمی‌دن سایت‌ها مستقیم عکس بذارن؛ عکس ذخیره‌شده رو موقع پست کردن اضافه کن.
- **مقایسه‌ی دو نفره (مرحله ۵):** هر نفر لینک خودش رو می‌فرسته (کپی، یا ارسال مستقیم در تلگرام و واتساپ). جواب‌ها فقط داخل خود لینک هستن و روی هیچ سروری ذخیره نمی‌شن. خروجی: درصد هم‌خوانی، علاقه‌های مشترک، «فقط من / فقط اون» و یه تصویر مقایسه.

## میزبانی رایگان روی GitHub Pages

1. فایل‌ها (`index.html`، `README.md` و پوشه‌ی `fonts`) رو در یه مخزن عمومی (public) آپلود کن.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**، شاخه‌ی `main` و پوشه‌ی `/ (root)` رو انتخاب و Save کن.
3. بعد از حدود یک دقیقه این آدرس فعال می‌شه: `https://<نام‌کاربری>.github.io/<نام‌مخزن>/`

## سفارشی‌سازی

- **برچسب‌ها:** آرایه‌ی `JARS`، **توضیح‌ها:** آرایه‌ی `JARS_INFO` (هر دو ۲۸ تایی و هم‌ترتیب).
- **رنگ‌های آماده:** آرایه‌ی `PRESETS`.
- **متن اشتراک‌گذاری:** ثابت‌های `SHARE_TITLE` و `SHARE_TEXT`.
